# ⚒️ Guildsmith

1. Bot erstellen: https://discord.com/developers/applications → New Application → Bot → Token kopieren.
2. `.env.example` zu `.env` kopieren und `GEMINI_API_KEY` (gratis: https://aistudio.google.com/apikey) + `DISCORD_BOT_TOKEN` eintragen.
3. Doppelklick auf `start.bat` (installiert alles und startet mit Tunnel).
4. http://localhost:3000 öffnen → Prompt eingeben → Plan → Ändern/Ja → Bot einladen → Build.

Hinweis: Die Bot-Rolle muss in Discord ganz oben stehen, sonst kann er Rollen nicht verwalten.
